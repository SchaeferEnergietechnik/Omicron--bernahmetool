# Bestehendes Python-Programm

Hier die vorhandene Python-Anwendung mit ihrer ursprünglichen Ordnerstruktur ablegen.

Bitte mitliefern:

- alle selbst geschriebenen `*.py`-Dateien,
- Konfigurationsdateien ohne Zugangsdaten,
- vorhandene `requirements.txt`,
- kurze Startanweisung, falls sie vom üblichen Python-Aufruf abweicht.

Installierte Bibliotheken, virtuelle Umgebungen und sensible Daten gehören nicht in diesen Ordner.
