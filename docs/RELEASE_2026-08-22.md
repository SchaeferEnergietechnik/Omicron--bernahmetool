## Fachliche Wirkung

- Kundenzuordnung aus Termine.xlsx erfordert nicht mehr nur exakte Namensgleichheit.
- Ein sinnvolles Teilwort zwischen Terminexcel-Kunde und Kundenliste kann ausreichen.
- Generische Rechtsform- und Fuellwoerter werden beim Matching ignoriert, zum Beispiel gmbh, ag, kg, co, und.
- Bei Mehrdeutigkeit wird eine Warnung protokolliert; die Verarbeitung kann trotzdem weiterlaufen.
- Wenn kein Kunde eindeutig gefunden wird, bleibt der bestehende Vorlagenkunde in `Allgemeine Angaben!C2` erhalten.
- Makrofehler verhindern den Laufabschluss nicht mehr; sie werden als Warnung protokolliert.
- Die Excel-Ergebnisdatei wird in jedem Fall gespeichert, inklusive Save-Fallback auf die Originaldatei bei SaveAs-Fehlern.
- Excel-Link-/Aktualisierungsdialoge werden fuer Nachtlaeufe unterdrueckt.
- Optional kann das System nach Laufende automatisch herunterfahren (standardmaessig deaktiviert).
